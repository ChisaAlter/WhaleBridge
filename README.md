# 鲸桥 · WhaleBridge

Magpie 源码的模型连接组件，默认接入鲸屿，也支持配置其他 Agent。鲸桥独立维护 Go 网关、管理页面、客户端适配器、组件版本及发布资产；鲸屿启动器负责下载、安装、停止、更新、回滚与卸载。

源码从 [WhaleIsle](https://github.com/ChisaAlter/WhaleIsle) 的 `vendor/whalebridge` 拆出，保留该目录截至 `1ea535956424c1af35806fed9065af0b3c1608ef` 的 18 次提交历史，并迁入正在开发的 1.2.0 多 Agent 接入功能。Go module 为 `github.com/ChisaAlter/WhaleBridge`，构建无需鲸屿源码或其 Node 依赖。

上游来源与 MIT 版权见 `upstream.json` 和 `LICENSE`。这里直接维护精简后的源码，构建不再下载完整 Magpie 或用 overlay 包装原应用。

- 删除上游主入口、CLI/TUI、Wails 桌面壳、原 GUI 和 Skills/MCP 管理页面。
- Agent 接入复用 `agentFeaturesCommit` 固定的上游内置适配器，与现有供应商能力使用同一基线。鲸屿固定为默认目标，仍自动同步，不覆盖其默认模型；其他 Agent 可读取当前模型与可选配置，显式接入、逐项应用和断开恢复。仅浏览页面不会写入客户端配置。只有用户在鲸桥中明确接入的客户端会同步模型目录；同步失败在该客户端页面显示。卸载恢复这些通过配置文件接入的客户端原配置，不接管独立 Magpie 已有的连接。Cindy 使用独立鲸桥来源的导入链接，导入确认与移除在 Cindy 内完成；需要启动环境的 CLI 由用户显式生成命令并在自己的终端运行，鲸桥不会代为启动。链接和命令包含连接凭据，仅在明确生成时显示。
- 保留供应商、模型目录、路由、协议转换和用量的源码依赖。订阅凭据续期、用户开启的暖机与自动签到、额度重置及订阅适配器更新由组件网关维护；不启动上游的客户端安装、原生客户端账号切换、会话扫描或远程监听任务。
- 私有本机网关提供模型目录、Chat Completions、Responses、Anthropic/Gemini 协议转换，以及供应商所需的图像、视频和嵌入能力。客户端配置使用组件持久密钥；Codex 原生登录通过私有端点保留原凭据。客户端安装、远程监听和用户 MCP 管理入口不开放。
- 自有设置页面提供接入概览、Agent 接入、供应商与账号、模型管理、路由组、用量统计、全局设置和使用说明。供应商、账号和密钥采用可搜索的管理列表；编辑工作台以分区导航组织连接、模型、请求限制、计费和专用配置，保存与取消固定可达。模型按渠道和供应商分组，保留三态显示开关、参数恢复与单模型价格草稿。路由提供嵌套成员、Go 规则匹配预览、固定推理等级、快速模式与批量管理。样式复用桌面壳的语义 token、滚动条和图标；透明 logo 与鲸屿 `assets/whale-head.png` 同源。
- 供应商和订阅保留上游配置与管理能力。自有页面和管理 API 同时接出模型选择与覆盖、多账号/密钥、并发和排队、价格倍率、代理、路由、认证及额度操作；供应商专用字段按所选预设显示。客户端配置适配由 Agent 接入页调用；CLI/TUI、原 GUI 和 Skills/MCP 管理仍不包含在组件中。
- 全局设置管理搜索 API、搜索与图像默认模型、脱敏、跨供应商价格、费用币种、网关 OTLP 遥测、加密备份和 WebDAV/S3 同步。同步只恢复供应商与相关设置；服务器已有的外部客户端、Library 与字体配置字段保留；字体字段只保存原始数据。请求账本提供账号/密钥归属、失败诊断、CSV、历史路由和 S3 归档查看下载；不扫描其他客户端会话。

添加供应商和接入订阅共用可搜索的模型来源目录，账号登录、API Key 套餐、供应商适配器、厂商、聚合服务及本机／远程服务分别显示。订阅入口默认显示账号和套餐，因此 ClinePass、OpenCode Go 及 Coding / Token Plan 也可在这里找到；选中 API Key 套餐进入预填的供应商编辑器，选中账号才进入登录表单。浏览目录不会自动登录、安装适配器或写入客户端配置；没有已安装适配器时，查询适配器目录也不会下载或启动其运行环境。上游动态赞助供应商单独标注，可按名称、ID、说明和中文类别搜索；使用其公共目录与缓存，不接入赞助曝光和点击统计。

`providerFeaturesCommit` 和 `agentFeaturesCommit` 固定本轮供应商、网关、目录、配置、同步及 Agent 适配器的 Magpie 来源；`providerDiscoveryCommit` 与 `searchFeaturesCommit` 继续记录目录和搜索来源。包含 Google Vertex AI、Bailian Token Plan、Qwen Decision、MLX-Serve，以及已有套餐地区和模型更新。Vertex AI 使用 Google Cloud 项目、位置及 Application Default Credentials，页面只保存凭据文件路径和可选代用服务账号，不读取或显示文件正文。ClinePass 的额度读取失败会与成功读取的余额同时显示。You.com 可无密钥使用，多个搜索密钥分别遮盖并由网关在被拒绝时依次尝试。组件适配层保留独立命名、私有网关、数据目录与受控接入语义；上游原应用的管理范围仍不启动。

1.3.0 将上述来源同步到 Magpie `1d6f461a`（2026-10-16），止于上游退役 13 个内置订阅适配器之前：Cursor、Qoder、Kiro、Zed、MiMo、Devin、Factory、WorkBuddy、ZCode、Grok、Command Code 等仍保留内置实现和「迁回内置」。上游把路由组、轮流 / 按权重等路由策略、隐私脱敏、联网搜索、插件工具、JS 网关中间件、网关密钥额度和 OTLP 导出改为通过自身插件运行时注册；组件没有插件页面，由 `Run` 直接注册这些能力并保持常开，行为与它们属于网关核心时一致。OTLP 导出移到 `internal/otlp`，仍只导出组件网关的调用，不启动客户端会话监视；请求分析同样不读取 Codex 身份库或桌面会话目录。供应商编辑器新增每日额度恢复时刻、连续失败后的最长休息时间、余额查询方式（GET / POST）、自建 HTTPS 服务跳过证书校验、Codex 原生压缩，以及自有供应商的模型列表自动刷新间隔与新模型自动加入规则；后两项在上游只能经 CLI 设置。StepFun Step Plan 会话按供应商保存，同一平台的两个供应商可以是两个账号，旧的按站点保存的会话自动迁移。上游此后新增、但在其窗口外设置的选项也接入组件页面：全局设置的「允许下载的内网地址」（`fetchPrivate`，上游只能手改 settings.json），Agent 页 Fast 模型的「超快」档（账号提供 Ultrafast 时），Codex 账号维护的自动重置时机（两种都用、仅周额度用尽或仅重置即将到期），供应商单模型的「不发送推理参数」，以及适配器页插件为其供应商声明的开关（需要确认的开关先询问）。Claude Desktop 接入后，其子代理模型与思考等级沿用 Agent 页的字段设置。DSH 渠道在启动时写不进去（例如配置锁被占用）不再让组件退出：网关照常启动，同步错误显示在状态中并在后台重试。

Agent 页支持各客户端独立模型名单、排序、只列出选中模型及适用模型的 Fast 模式。接入方案保存当前明确管理的外部 Agent 字段与模型名单，应用时只处理仍已明确接入的客户端；不保存或应用 Library、MCP、未接入客户端及鲸屿默认连接。内置客户端采用该来源的 63 项登记，其中 Claude Science 需要重启它自己的后台进程才能接入，鲸桥不提供，实际列出 62 项；插件也可提供客户端适配器。

适配器与中间件页按供应商认证、请求中间件和 Agent 接入分类，提供运行钩子、调用次数、失败与耗时信息，并管理启停、配置和更新。多个插件提供同一供应商时可保存优先归属。窄窗口将已安装项的状态和操作逐项显示，长包名或本地路径换行。

供应商工作台接出每个身份的 RPM、额度冷却、额外 JSON 请求字段、认证头和请求来源选项；可保持账号与额度查询而选择零个模型。路由组支持成员权重、忙碌等待预算、仅展示组入口，以及按项目目录、时段或星期选择和暂停成员。目录合并多个协议端点并读完分页，保留暂时失败端点的旧模型；协议转换保留结构化输出参数，媒体与嵌入请求按可用密钥分配。

订阅维护包括保存账号的显式额度刷新、账号别名、每账号签到开关、每日多个预热时间、撤销授权状态与重置使用记录。全局设置可关闭自动发现订阅凭据或选择仅在手动要求时查询额度；搜索和识图模型可独立指定思考等级。请求分析使用组件实际请求，提供 Agent 分组、日期范围、请求日历、重试筛选与窗口估算，不读取原生客户端会话文件。备份同步支持 WebDAV、S3 和 GitHub 私有仓库；遇到外来或损坏的远端文件时显示诊断，明确上传前保留旧远端。S3 端点缺少条件写入时按上游重新读回与合并可观察到的竞争变化，不保证服务本身不可观察的写入窗口。

适配器安装在原按钮文字后显示转圈，文字按后端真实阶段从“下载中”切换为“安装中”；更新显示“更新中”。结果在当前对话框提示。操作期间锁定相冲突的设置，关闭对话框后后台安装仍继续，但不会重开已关闭的界面。供应商操作菜单在按钮旁弹出，支持方向键和 Escape，表格滚动不会裁切菜单。普通下拉框保留原生键盘操作，箭头使用主题颜色与统一留白。

弹窗用遮罩区分前后景，不实时模糊整个背景；转圈使用独立图层旋转，避免软件渲染环境下背景模糊与持续动画叠加造成卡顿。

操作结果提示在工具栏下方占用独立空间，不遮挡内容区的保存、恢复或撤销按钮；长错误正文在提示内滚动，关闭按钮始终可达。保存和登录轮询的返回只更新发起操作的编辑器；设置保存只清除提交时未继续修改的原页面草稿。

从本仓库根目录执行 `node scripts/build.mjs`，需要 Node.js 24 和 Go >= 1.26.8。输出 `.tmp/whalebridge-package/WhaleBridge-win32-x64.exe`、`WhaleBridge-component.json` 和 `LICENSE`；可用 `--out <目录>` 将产物写入鲸屿开发目录的 `.tmp/whalebridge-package`，供源码启动器安装。图标和页面资源已保存在本仓库，不在构建时读取鲸屿资产。

`upstream.json` 管理组件版本和上游来源。发布沿用 `whalebridge-v<版本>` tag、原二进制名称和大小/SHA256 清单，保持现有安装、升级与回滚协议。源码拆仓不改变组件的启动方式；仍由鲸屿启动器提供运行目录和默认鲸屿 home。

独立 Windows 工作流验证网关、供应商、设置、用量和鲸桥 API，运行实际二进制启动检查及四组页面交互回归。页面检查依赖固定的 Electron 44.2.0：`pnpm install --frozen-lockfile --ignore-scripts` 后执行 `node node_modules/electron/install.js`、`pnpm test:web`。鲸屿宿主的安装/更新/回滚和原生管理窗口 QA 留在鲸屿仓库，使用独立构建产物，不再解析组件源树。

工作分支与 PR 不发布组件；成功的 main 构建才发布未存在的组件版本。稳定版 1.1.0 的原始二进制和清单已迁入独立 GitHub 仓库，宿主的匿名发现、下载校验、安装、启动、停止与卸载已验证；新的 1.2.0 多 Agent 功能与独立工作流保留在开发分支，等待合入。

组件的 CNB 工作流位于本仓库，继续分发到共享镜像 `ayasealter/WhaleIsle`，只推送选中的新组件 tag，不推送或改写鲸屿 main，也不推送全部历史 tag。旧版 1.1.0 的 CNB tag 保持原宿主来源，新流程从独立仓库的新版本开始。Actions secret `CNB_TOKEN` 已经由旧仓库通过目标仓库公钥加密迁入，明文未离开加密步骤；原凭据和旧仓库手动关闭的发布、镜像工作流保持原状。新组件 tag 的实际镜像和匿名下载校验待首次独立发布时确认。

上游 Agent 测试整包在 Windows 尚未通过：部分离线案例使用 Unix 文件权限或需要 symlink 权限，Codex 的陈旧进程测试要求 Windows 实现明确不提供的进程判定。测试及断言保持原样；工作流验证组件 API 接出的行为和可在 Windows 上运行的七项格式恢复案例，不宣称上游 CLI 全量验收通过。

进程需要启动器提供 `LAUNCHER_COMPONENT_DATA_DIR`、`WHALEBRIDGE_DSH_HOME` 和 `MAGPIE_ADDR`。管理页采用随机端口及私有 Cookie；网关绑定本机、使用持久随机密钥。供应商列表默认遮盖密钥，只有用户主动显示或导出时才返回完整凭据。关闭设置窗口不停止网关；DSH 启动时恢复已安装组件。

DSH 只修改 `home/profiles/web/cordis.patch.yml` 中 `llm-pi-ai` 的 `providers.whalebridge` 和自身 `.env` 凭据，使用 DSH 的 profile 写锁并支持运行时热更新；不覆盖其他供应商或默认模型。后台模型刷新和自动同步也更新这一渠道，失败在管理页显示。模型、供应商和全局压缩阈值按优先级投影为 `compactionThreshold`，由 DSH 的 LLM 元信息传递至实际压缩消费者；完整窗口模式保留输出预算与安全余量。卸载移除这一渠道；如果它是当前默认模型则清除该默认选择。聊天记录保留。组件自己的配置和用量可在卸载时选择保留或删除。

同类异步操作在原按钮中显示当前动作和末尾转圈：模型刷新与测试、账号和密钥维护、适配器检查与更新、设置保存、备份、同步和额度读取。图标按钮及开关在原热区显示转圈；等待状态不增加正文行，完成或失败后恢复控件并显示结果。
