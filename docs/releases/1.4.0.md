鲸Bridge 1.4.0 整合已发布 1.3.0 的能力与本轮上游适配、网关运行时和原生界面修复。组件显示名统一为「鲸Bridge」，技术 ID、启动协议、更新资产名称和本机数据目录保持兼容。

### 主要更新

- 13 个退休订阅供应商 ID 通过适配器继续连接，保留账号顺序、停用状态、模型选择及移除记录。自动交接仅处理组件拥有的完整账号批次；借用客户端的身份需要显式操作。
- 多账号模型目录取并集，保留暂时下架的选择并在恢复上架后重新提供；协议可用性、服务等级、不发送思考字段和输出预算设置贯通到实际请求与鲸屿模型渠道。
- 新增「免费优先」路由，支持供应商、路由组以及适配器报告的策略。网关运行时按依赖装配、等待正在进行的回复后热更新，退出时回收观察器、工作任务和子进程。
- 搜索支持密钥轮换、失败冷却、Tavily 额度、自定义排序和停用；完善 DeepSeek Search、Nous Portal、SiliconFlow 国际站、Bedrock Mantle 与自定义 POST 余额读取。
- GitHub 大备份采用分片和原子提交；Codex 图片处理使用有界工作池、内存预算和缓存。媒体下载遵循显式私网授权与供应商精确端点范围，搜索和请求脱敏出错时停止出站。
- 完善取消登录、令牌续期、损坏账本与 HTTP/2 失活连接处理。保留 1.3.0 的 DSH 写锁后台重试、Agent 适配、Ultrafast、供应商自动目录维护、插件选项及预算配置。

### 界面与响应

- 重做用量统计：四项指标对齐呈现，可交互的请求、Token 与费用趋势图，集中切换模型、Agent、账号和 API 密钥分布；空周期只显示一次空状态，不再铺满零值条形和空分类框。
- 修复用量与设置页签上下留白、模型下拉箭头、密钥筛选与日期表单分组、行内复选框及加载图标对齐；完善窄窗工作台、徽章和操作间距、备份表单标签、自定义脱敏规则网格，以及请求归档和路由错误长文本换行与留白。
- 大模型目录的读取、Agent 接入和模型同步复用带写入失效与短 TTL 的目录快照，减少重复解析造成的长时间等待。
- 本轮原生审查覆盖亮暗主题和六种窗口组合；完整审查记录及验证边界见仓库中的 `docs/ui-layout-audit-2026-10-23.md`，发布整合验证见 `docs/release-validation-1.4.0.md`。

### 升级

在鲸屿启动器的组件页更新。已有配置、账号、路由、用量与鲸屿对话记录保留。退休供应商如提示需要交接或更新适配器，请按管理页的实际状态操作。

发布包含 Windows x64 可执行文件及配套组件清单。清单记录版本、文件大小和 SHA256；供应商可用性及授权仍由对应供应商决定。
