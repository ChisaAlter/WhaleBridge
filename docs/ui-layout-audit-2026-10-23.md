# 鲸Bridge原生 UI 全量审查 · 2026-10-23

本轮将组件的用户可见名称统一为「鲸Bridge」，并在本机运行独立构建的 Windows 组件，检查管理页、编辑工作台、对话框、长目录和低高度窗口。组件技术 ID、环境变量、磁盘数据路径和升级协议仍使用 `whalebridge`，保持现有安装兼容性。

## 审查方式

使用 Electron 44.2.0 的真实 BrowserWindow 加载组件实际 Go HTTP 服务及内嵌资源。私有启动凭据先交换为管理 Cookie；页面请求由真实管理 API 处理。点击使用鼠标命中测试，记录实际 viewport、主题、根容器宽度、文本裁切、重复可见 ID、弹窗边界及保存／取消／关闭按钮可达性，并保存原生窗口截图。表格和横向分区导航的容器内滚动视为有意设计。

后端使用独立 HOME、AppData、XDG、DSH profile 和组件目录；PATH 与 ProgramFiles 系列目录指向本轮自有目录，关闭自动 WSL 探测。供应商与 S3 端点仅使用本机回环测试服务，禁止测试代理向外网转发。Windows 安装信息的只读注册表探测仍可能发生；未将此夹具表述为完全禁止机器安装信息检测。

实际数据规模：21 个供应商、1055 个暴露模型、12 个路由组、10 个订阅账号、12 个供应商密钥和 50 条预置用量记录。另通过真实网关生成 6 条请求，5 次成功与 1 次预期失败，保留完整模型目录。归档由 Go 写入本机 S3 后，再经真实归档 API 读回并显示；没有 mock `/api`。

## 已修复问题

| 问题 | 改动与影响 |
| --- | --- |
| 加密备份导出和导入的密码控件共用 DOM ID | 导出密码、导入密码和导出密钥开关使用独立 ID；标签准确关联本表单控件，提交字段名保持兼容。 |
| 自定义脱敏规则实际四个子项与桌面网格定义不一致 | 改为三列可伸缩输入和一列操作；窄窗继续逐项堆叠。 |
| 请求归档的长 Header、JSON 和详情定义列表缺少一致换行与留白 | 增加归档容器、统一预格式化文本换行与最大高度、清除详情默认缩进，保留独立滚动。 |
| 路由错误详情长 ID／错误文本接近边框 | 增加两侧内边距和任意位置换行。 |
| 大目录管理和真实请求重复解析设置及构建目录，导致读取、接入和同步长时间等待 | 复用上游短期 Hold 机制，管理 GET、经过认证的网关请求、Agent 接入规划、DSH 同步和已受管 Agent 同步在操作结束释放；写入显式使目录缓存失效。缓存有 1 秒 TTL，不在网络请求期间持有业务互斥锁。 |
| 窄窗显示额度提醒后，长面包屑被挤成多行 | 窄窗工具栏按完整子块换行，面包屑和操作区不缩小；覆盖全部 8 个一级页面。 |
| 组件旧显示名分散在页面、运行日志、渠道及清单 | 用户可见名称统一为鲸Bridge，保留旧名称迁移兼容测试和技术标识。 |

## 回归与证据

完整六组合矩阵完成 959 个检查点，另完成 3 个组合的 57 个补充检查点，加上最终工具栏 18 个定向检查点，合计 1,034 个；页面根容器溢出、文本裁切、弹窗越界和固定操作区遮挡均为 0；运行错误为 0。原始矩阵有 1 项窄短窗菜单脚本失败：点击工具预先打开其父菜单，再点击 summary 把菜单关闭。已排除 `details.menu` 的自动展开，补充矩阵保留真实鼠标定向复测。隐藏在账本 details 内的详情按钮仍先展开普通详情父项。原始失败报告保留，汇总报告明确关联修正原因与复测结果，不改写旧结果。补充报告状态为 passed，12 个新增／复测界面状态在桌面亮色、窄窗暗色和窄短窗亮色下均通过；新增测试时供应商选项改为使用 API 返回的真实 ID，授权从选项、两轮提问、等待、回调到成功均实际走通。账号导入使用缺少 refresh token 的合成数据，验证失败结果页和保存完成反馈，不接触真实凭据。60 条提醒为 UI 压力数据。此后截图复核确认窄窗长面包屑在出现提醒时被挤压，已补 CSS 完整子块换行；最终 8 个一级页面在窄窗暗色和窄短窗亮色下的 18 个工具栏检查点全部通过，0 布局或运行错误。
