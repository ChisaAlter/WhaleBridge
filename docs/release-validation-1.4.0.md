# 鲸Bridge 1.4.0 发布整合验证

## 来源与版本

本次发布整合开发提交 `3ee65c53e5ad2b5f558363062cf304e16ad2a4ee` 与已发布 1.3.0 的主分支 `dc40ce50eb839019f11e3a83a17d0e51a9e0d2b3`，共同祖先为 `33b68f567c4e314fdc40953aebc507d5a2497e64`。在独立工作树中逐功能解决合并，原开发工作区和已安装组件保持独立。

完整供应商、目录、搜索与 Agent 来源保留 1.3.0 的 Magpie `1d6f461a99d6bae2cb5357899345d8818739031e`，归档 SHA256 `bab746000f3d9c2a5b22607b915058d6f9cf7c0bc4944ec9f0c82cb8f4117032`。另保留截至 `e00fbdbbc74f9829027a78769cbeb265d6271fb4` 的核查快照与 50 条局部补丁来源。核查快照不表示完整同步该快照。

组件稳定版本递增为 1.4.0，使用 `whalebridge-v1.4.0` 标签；更新协议、组件 ID、资产名及配置路径保持兼容。13 个内置订阅供应商 ID 退休并转向适配器，是本版本明确的行为变化，遵循所有权、停用、移除及失败回滚边界；不将该变化描述为继续提供旧内置请求路径。

## 整合要求

- 保留 DSH 初次同步失败后网关仍可服务、状态可诊断及后台指数退避重试；重试纳入组件工作任务的取消与等待生命周期。
- 保留已发布版本的供应商高级控件、按供应商隔离的 StepFun 会话、Codex 重置时机、Ultrafast、插件声明选项与设置格式；普通保存不抹去旧版本配置。
- Claude Desktop 的逐模型上下文方案与鲸屿渠道的默认输出预算各自保留。已有 Agent 适配及用户配置恢复不因本次合并退回旧实现。
- 保留本轮有限网关装配与热更新生命周期；每项注册和请求观察仅执行一次，不同时调用旧静态装配。原生压缩保留账号和检查点约束。
- 保留 1.3.0 的显式本机媒体私网授权编辑功能，沿用本轮精确端点、重定向、DNS 和 fake-IP 下载守卫。备份与同步携带的数据不能提升当前机器的私网授权。

## 验证边界

本机回归使用隔离用户与组件目录、回环供应商及 S3 夹具；没有使用真实供应商凭据、付费调用或用户远端备份。页面认证与媒体授权测试经过实际组件管理服务。现有安装及聊天记录不由本次发布操作替换。

此前开发树的 1,034 个布局检查点记录在 [UI 审查记录](ui-layout-audit-2026-10-23.md)；它们与本次合并后的发布候选验证分别记录，不能用开发树旧结果代替整合版本结果。最终发布的二进制大小和 SHA256 以该版本的组件清单与公开下载复核为准。
