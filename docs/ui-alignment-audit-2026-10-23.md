# 鲸Bridge 1.4.0 界面对齐复核

用户指出用量统计页签仍偏上。本轮在独立发布工作树修复，并重新检查嵌入实际组件的页面、工作台、弹窗、工具栏和加载状态。此记录归档正式发布前的对齐审查；审查期间没有替换已安装的 1.3.0。

## 直接原因与修复

`.segments.page-segments` 原先同时命中 `padding:4px` 与 `padding-bottom:12px`，另有底边框。实际测量顶端留白 4px、底端 12.67px，差值 8.67px，选中页签相对轨道中心上移约 4.3px。按钮内部的 flex 居中规则本来正确。

修复为轨道四边统一 4px，移除该轨道的底边框。用量四个页签和全局设置五个页签共用修复，包含窄窗换行；模型页独立的筛选轨道保持自己的布局。最终测量顶部与底部均 4px，60 个轨道样本的最大差值为 0。

## 全界面修复

- 单模型参数的 select 顶部间距移至包装容器，内部 select margin 归零，箭头对准真实输入框中心。
- 自定义脱敏规则清除标签上下 margin，标签和控件使用明确的 8px 间距，输入、下拉框和移除按钮底边一致。
- 481–760px 宽、隐藏分区导航的工作台只保留一行内容，避免多余网格行占据滚动空间。
- 历史日期表单沿用字段分组；密钥筛选分别包装标签和控件，在换行后仍保持成组与底边对齐。
- 账本与适配器工具栏的行内复选框清除普通字段 margin；Agent 复选框统一尺寸与 margin，Fast 控件垂直居中。
- 加载环移除与按钮 gap 重复的左 margin；文件读取、图标上传和镜像保存的非按钮宿主使用明确的 inline-flex 与 8px gap。
- CSV 导出链接采用按钮相同的高度和居中几何；全局保存提示使用既有 caption 布局规则。
- 账号与自动路由组状态徽章补外部 gap；管理表的两排操作和统一价格操作按钮补组间距。
- Agent 模型空搜索结果补内边距；请求日历重置首标题间距并补与筛选栏的间距；额度与路由操作栏同样补区块间距。
- 信息图标单独校准 viewBox，使图案中心与盒中心一致。

导航、菜单、字段值、代码、路径、长模型名和多行表格仍按原有阅读方向排布。检查器分别验证垂直中心、显式居中控件的水平内容组合、行内控件中心或底边。

### 中断与告警处理

第一次完整运行完成桌面浅色、深色及 820px 三组后，在窄窗 Agent 切换步骤等待超时。测试补强为先等待选择器解锁，再切换并等待解锁；Agent 操作等待上限单独增加到 45 秒。三组剩余窗口使用同一最终二进制完整补跑，每组均完成 160 个检查点。没有把超时运行本身标为完整通过。

补跑原始报告包含四个 `key-routing` 视图、80 条水平中心告警。对应按钮为明确 `text-align:left` 的长模型名，换行文字应左对齐，其文字盒由 flex 排布。检查器原先错误地比较多行字形并集的水平中心。修正规则保留垂直中心检查，水平检查遵循显式文本方向；四个对应状态在控件专项中全部复测通过。文件读取按钮原先漏算嵌套加载环也已修正并复测。原始报告与复测报告分别保留，没有擦除告警。
